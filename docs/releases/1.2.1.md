# Patreon Reader 1.2.1 release preparation

Prepared locally on November 6, 2026. Manifest, package and lockfile metadata
agree on 1.2.1. No 1.2.1 store ZIP has been generated in this preparation, and
upload, approval or publication has not been confirmed. The user confirmed that
[1.2.0](1.2.0.md) was approved and published; that is the previous release.

## Changes from 1.2.0

- Add a bundled, locally loaded Noto Sans SC fallback for supported CJK PDF text,
  including 天. It does not cover every Unicode character or regional typography.
- Make PDF chapter names in contents visibly blue and underlined.
- Keep collection front matter while removing repeated metadata inside combined
  PDF/EPUB/Markdown chapters. Individual posts and ZIP chapter files keep their
  Creator, Download time and Source details.
- Identify font-failing PDF posts by title, number, character error and source
  link, retaining prepared data for retry.
- Move Download report below format choices. Show confirmed completion totals
  and failed-post details without report-file downloads or file inventories.
  Skipped, cancelled, saving and unconfirmed posts remain distinct from failures.
- Reconnect a refreshed collection tab to an idle, unexpired session for the same
  tab, window and collection. Recovery does not extend expiry by itself.
- Replace a stale collection chooser after extension reload with refresh guidance
  and a user-controlled Refresh page action. Existing tabs need one manual refresh
  after first loading the fix so they receive the new recovery code.
- Handle synchronous extension API failures through existing rejection handlers,
  preserving permission-request user gestures.

See the [changelog](../../changelog.md) and [user guide](../usage.md) for details.

## Privacy and storage

Export processing stays local; requested content/images are retrieved directly
from Patreon and approved image origins. There is no new telemetry, backend,
permission or network destination. The canonical collection URL is retained in
existing browser-session metadata to support scoped reconnection. Reports remain
in page memory and cannot be saved as separate report files. CJK fonts are bundled,
not fetched remotely. The two-hour cache policy, 512 MiB source disk budget,
separate 1 GiB archive payload budget, encryption and browser-session cleanup
remain in force. See [Privacy Policy](../../PRIVACY.md) for exact retention limits.
