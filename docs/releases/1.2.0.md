## Scope

- Comfortable reading with saved font, size, colour and spacing preferences.
- Accessible post downloads as PDF, EPUB and Markdown with inline images.
- Collection downloads in all three formats, as a combined file or separate files
  in a ZIP, oldest first, with numbered parts for larger collections.
- On-demand discovery, two-hour source reuse, cancellation/retry, progress and
  local reports with browser-confirmed completion/interruption.
- Popup identity/version and community links; existing engagement-bar fixes.

See [changelog](../../changelog.md), [privacy policy](../../PRIVACY.md),
[release validation](../../TESTING.md) and [packaging](../release-packaging.md).
The policy describes direct Patreon/media requests separately from local export
processing; the extension has no developer-operated export backend. Existing
permission declarations and export behaviour are unchanged by this release
preparation task. The export status copy now says “Files are generated locally”
instead of the overbroad “Nothing leaves this browser.” The store's privacy answers still require a dashboard review.

## Package and screenshots

Build with `npm run package`. The upload candidate is
`dist/patreon-reader-1.2.0.zip`; `manifest.json` is at its root. The archive
validator checks exact allowlisted resources and byte equality with the source.
The ZIP is ignored by Git; retain the local artifact and its SHA-256 when uploading.

Candidate SHA-256:
`1cc620bc6a9a462071822fb6671672f66153e975ea953a931310f8895742c738`.
A rebuild can change ZIP bytes through tool metadata; recheck the checksum against
capture provenance and record the exact uploaded artifact.

After validation, run `node scripts/capture-store-screenshots.js`. This validates
and extracts that ZIP and loads the extracted extension in an isolated Brave
profile. It captures genuine runtime UI at 1280 × 800 using synthetic, visibly
labelled demo pages with no real post text, accounts, signed URLs or credentials.
The screenshots are not evidence of current live Patreon compatibility. They are
not composited or edited to add extension controls. Network routes supply only
local demo content. Capture provenance records the package and image hashes.
